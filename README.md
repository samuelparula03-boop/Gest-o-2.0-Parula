# Gestão de Tarefas Executiva (Google Tasks + Agenda)

Este é o repositório do seu painel de gerenciamento de tarefas.

## Como subir no GitHub sem usar terminal:

1. Baixe e descompacte este arquivo ZIP no seu computador.
2. Acesse o seu repositório no GitHub: https://github.com/samuelparula03-boop/Gest-o-2.0-Parula
3. Clique no link **"enviando um arquivo existente"** (uploading an existing file).
4. Selecione e arraste TODOS os arquivos descompactados para a tela do GitHub.
5. Clique no botão verde **"Commit changes"** no final da página.

## Como publicar na Vercel:
1. Acesse https://vercel.com
2. Faça login com o seu GitHub.
3. Clique em **Add New... > Project**.
4. Selecione o repositório `Gest-o-2.0-Parula` e clique em **Deploy**.
